NAVYA MOBILE ZONE — WEBSITE FILES

Files:
- index.html: website content
- style.css: colors, layout and responsive design
- script.js: mobile navigation and current year

HOW TO PUBLISH WITH GITHUB PAGES:
1. Open your GitHub repository: Navya-Mobile-Zone-Akividu-
2. Upload all three files (index.html, style.css, script.js) to the repository's main/root folder.
3. Open the repository's Settings.
4. Find Pages (usually under the "Code and automation" section).
5. Under Build and deployment, choose "Deploy from a branch".
6. Select branch "main" and folder "/ (root)", then Save.
7. Wait a few minutes for GitHub Pages to publish the site.

BEFORE SHARING THE WEBSITE:
- Add the shop's real phone number and exact address.
- Confirm the Google Maps location is correct.
- Add real product photos, prices and available brands if you want to show exact stock.
- This first version is a shop information/category website, not an online checkout store.
- The Google Fonts import needs an internet connection; the page still has fallback fonts.

- navya-logo.jpg: artwork supplied for Navya Mobile Zone; keep it alongside index.html.
